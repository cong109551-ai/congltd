## 📖 项目简介 (Overview)

`cong.ltd` 是一个追求极致美学与工程工艺的现代个人工作室网站。采用深邃黑夜与深空极光（Aurora Borealis）视觉设计，融合胶片棱镜光斑动效与克制的微交互，为访客提供沉浸、温润且具科技质感的品牌体验。

- **官方仓库**: [https://github.com/cong109551-ai/congltd](https://github.com/cong109551-ai/congltd)
- **核心信念**: 坚守诚信底色，追求极致交付速度，秉持真诚同理心。

---

## ✨ 核心特性 (Features)

1. **沉浸式极光开屏 (Aurora Hero & Intro)**
   - 慢速深空极光色带算法流淌，搭配电影级变形棱镜光斑与胶片微闪。
   - 响应式单行防折断排版，全平台自适应展现。

2. **字体与排版美学 (Typography)**
   - **英文**: IBM Plex Sans，工业理性、骨架利落。
   - **中文**: Noto Sans SC（思源黑体），字形舒展舒朗、温润雅致。
   - **代码/微标**: JetBrains Mono。

3. **动态极光实验室 (Studio Lab)**
   - 实时光效调优视窗，支持光流速度（30s~180s）、色散、模糊度与主题色系切换。

4. **工作室服务与精选作品 (Services & Works)**
   - 全栈研发、高保真界面设计、架构咨询与工程落地案例陈列。

5. **响应式与无障碍 (Responsive & A11y)**
   - 移动端至超宽屏自适应，WCAG AA 高对比度色彩与细腻触控交互反馈。

## 🚀 本地开发与启动 (Getting Started)

### 1. 克隆仓库
```bash
git clone https://github.com/cong109551-ai/congltd.git
cd congltd
```

### 2. 安装依赖
```bash
npm install
```

### 3. 启动开发服务器
```bash
npm run dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000)。

### 4. 生产打包
```bash
npm run build
```
